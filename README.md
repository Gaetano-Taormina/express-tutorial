# Esercizio 1 — Scaffolding manuale: il nostro primo server

## Descrizione
Creazione manuale dello scaffolding di un progetto Node.js ed Express senza generatori automatici.

## Requisiti realizzati
- `pnpm init` e installazione di `express`
- Configurazione ES Modules (`"type": "module"`)
- Script `dev` con `node --watch server.js`
- File `.gitignore` per escludere `node_modules`
- `server.js` minimale con rotta GET su `/` e ascolto su porta `3000`
